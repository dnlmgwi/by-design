# Graphic Design Master Class
## Lecturer's Guide for Daniel Mgawi

This comprehensive guide provides detailed instruction plans, learning objectives, demonstration recommendations, and discussion points for each session of the Graphic Design Master Class.

## Module 1: Design Fundamentals

### Week 1: Introduction to Design Principles

#### Session 1: Elements of Design

**Learning Objectives:**
- Identify and describe the basic elements of design
- Recognize how these elements interact in successful designs
- Begin developing visual analysis skills

**Lecture Content:**
- Define and illustrate design elements: line, shape, color, texture, space
- Show examples of how each element functions in different designs
- Present historical context for fundamental design principles

**Demonstrations:**
- Interactive analysis of selected designs, breaking down their elements
- Show before/after examples of designs with modified elements

**Discussion Points:**
- How do designers use fundamental elements to communicate?
- How have design elements evolved with digital media?

**Assignment Preparation:**
- Visual analysis worksheet for students to apply to designs of their choice

#### Session 2: Principles of Design & Gestalt Theory

**Learning Objectives:**
- Explain key design principles and their application
- Understand the psychological basis of visual perception
- Apply Gestalt principles to analyze and create designs

**Lecture Content:**
- Design principles: balance, contrast, emphasis, rhythm, unity
- Introduction to Gestalt psychology and its impact on design
- Review of contemporary design trends stemming from these principles

**Demonstrations:**
- Interactive examples showing principles in action
- Side-by-side comparisons of designs with strong vs. weak application of principles

**Discussion Points:**
- How do various design fields apply these principles differently?
- When might you intentionally break design principles?

**Assignment Preparation:**
- Guidelines for the visual analysis practical exercise

## Teaching Resources

### General Teaching Tips
- Begin each class with a quick review of previous concepts
- Use a mix of lecture, demonstration, and hands-on practice in each session
- Allocate time for questions at natural break points
- Consider recording key demonstrations for student reference
- Use collaborative features in Figma for real-time feedback during exercises

### Lecture Materials Checklist
- Presentation slides (with visual examples)
- Exercise files and templates
- Reference images and case studies
- Tutorial links and resources
- Assignment briefs and evaluation criteria

### Demonstration Setup
- Prepare Figma files before class
- Check screen sharing settings and resolution
- Consider using a tablet for drawing demonstrations
- Have backup examples ready in case of technical issues
- Prepare simplified versions of complex demonstrations

### Assessment Strategies
- Provide clear evaluation criteria for all assignments
- Balance technical execution with concept development
- Consider peer review opportunities for selected projects
- Provide both written and visual feedback on work
- Document student progress throughout the course

### Classroom Management
- Establish ground rules for critiques and discussions
- Balance attention between advanced and beginning students
- Create opportunities for peer learning and collaboration
- Address technical issues promptly or provide workarounds
- Maintain a positive, supportive learning environment
